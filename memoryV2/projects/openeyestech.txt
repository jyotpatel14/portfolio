Project Overview

The OpenEyesTech Marketing Application was a production-grade Flutter application developed to enhance user engagement during live events and exhibitions through interactive digital experiences.

The application was designed around QR-driven workflows that allowed event attendees to access content, navigate between application modules, participate in quizzes and puzzles, and engage with event experiences through streamlined mobile interactions.

The project holds special significance in Jyot Kalpesh Patel's professional journey because it was the first production-grade application in which he contributed end-to-end, participating in development, optimization, experimentation, technical evaluation, and cross-team collaboration.

Project Vision

The primary goal of the OpenEyesTech Marketing Application was to increase attendee engagement at conferences, exhibitions, and promotional events by providing an interactive mobile platform.

The application aimed to:

- Improve visitor engagement.
- Simplify event navigation.
- Create interactive user experiences.
- Increase participation through gamification.
- Connect physical event experiences with digital workflows.
- Enable scalable event engagement mechanisms.

Key Features

QR-Driven Navigation System

One of the application's defining features was its QR-driven workflow architecture.

Users could scan QR codes at events and immediately access relevant application sections without manually navigating through menus.

Benefits included:

- Faster user onboarding.
- Improved navigation efficiency.
- Reduced interaction friction.
- Better event engagement.

Deep Linking Architecture

Jyot contributed significantly to the implementation of deep linking functionality.

Deep linking enabled:

- Direct navigation to specific screens.
- QR-triggered experiences.
- Context-aware user journeys.
- Faster access to event content.

This architecture improved the overall user experience and reduced unnecessary navigation steps.

Quiz and Puzzle Engagement Modules

The application included gamified engagement features such as:

- Interactive quizzes.
- Puzzle challenges.
- User participation systems.
- Event-based rewards and engagement mechanisms.

These modules helped increase attendee interaction during exhibitions and events.
